# Сервер «Порции»

API на FastAPI. Основная база — PostgreSQL, работа с данными через SQLAlchemy. Для тестов используется отдельная SQLite. Домашняя модель подключается через Ollama; личные настройки в репозитории отсутствуют.

## Запуск
1. Скопировать `.env.example` в `.env`.
2. Указать собственные `POSTGRES_PASSWORD` и `JWT_SECRET`, согласовать `DATABASE_URL` с параметрами PostgreSQL.
3. Задать `OLLAMA_BASE_URL`, доступный из контейнера API, и имя установленной модели в `OLLAMA_MODEL`. Значение `your-model-name` — заглушка.
4. Запустить `docker compose up -d --build`.

Compose по умолчанию привязывает API к локальному интерфейсу. Для подключения телефона нужно отдельно настроить адрес публикации и доступ в своей сети. Модель Ollama развёртывается отдельно. Данные базы и кеш цен сохраняются в Docker-томах.

## Основные файлы
- `app/main.py` — маршруты API и модели запросов.
- `app/models.py`, `app/db.py` — таблицы и подключение к базе.
- `app/recommender.py`, `app/recommendation_rules.py`, `app/recommendation_scoring.py` — подбор меню, порции и оценка кандидатов.
- `app/food_filters.py` — проверка пищевых ограничений.
- `app/recipe_catalog.py`, `app/base_recipes.py`, `app/curated_recipes.py`, `app/expanded_recipes.py` — каталог и рецепты.
- `app/nutrition.py`, `app/nutrition_reference.json` — расчёт КБЖУ и справочник ингредиентов.
- `app/menu_ai.py`, `app/plan_preferences.py`, `app/meal_replacement.py` — работа с моделью при подборе, пожеланиях и замене.
- `app/store_prices.py`, `app/magnit_prices.py`, `app/product_search.py` — торговые предложения и поиск продуктов.
- `app/store_map.py` — магазины и пешие маршруты.
- `app/security.py`, `app/coach_safety.py` — вход, токены и ограничения помощника.

## Данные и ограничения
В каталоге 79 блюд, в справочнике 99 ингредиентов. Источники адаптированных рецептов указаны в записях каталога. ИИ выбирает допустимые блюда, не создавая новые рецепты. При ошибке модели остаётся подбор по программным правилам.

КБЖУ являются справочной оценкой по массе ингредиентов. Плановая стоимость не подтверждает кассовые цены. Поиск магазинов не гарантирует наличие товара; заказ и оплата не реализованы. Сроки хранения зависят от данных каталога и требуют проверки. Пищевые фильтры проверяют записанный состав рецептов и метки, а не маркировку конкретной упаковки.

Домашний запас учитывается при составлении закупки, но не списывается автоматически. Чеклист хранится в Android-клиенте.

## Тесты
Установить зависимости из `requirements.txt` и pytest. Задать отдельные тестовые `DATABASE_URL` и `JWT_SECRET`, затем выполнить `python -m pytest -q` из этой папки. Тесты используют сохранённые примеры торговых данных и подмену ответов модели; они не подтверждают текущие цены или доступность реальной Ollama.

`.env`, локальные базы, ключи и кеши исключены из Git и Docker build context. `.env.example` содержит только шаблоны.
